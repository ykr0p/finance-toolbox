# Finance Toolbox 📈

Современная открытая веб-платформа для моделирования личных финансов, планирования финансовой независимости (FIRE), стресс-тестирования инвестиционных портфелей методом Монте-Карло и сравнительного анализа доходности классов активов.

---

## 🌟 Ключевые возможности

### 1. Калькулятор финансовой независимости (FIRE)
- **Два режима моделирования:**
  - *Простая версия:* экспресс-оценка необходимого капитала, возраста и срока достижения цели с минимальным набором понятных параметров.
  - *Гибкая версия:* детальный расчёт с учётом подушки безопасности, индексации сбережений, инфляции расходов, реинвестирования дивидендов и множителя капитала (100% или 200% покрытие расходов).
- **Интерактивная визуализация:** график накопления капитала и инфляционной цели с автоматическим определением точки пересечения (выхода на пенсию).
- **Годовая детализация:** пошаговая таблица симуляции по годам с возможностью экспорта результатов в CSV.

### 2. Симуляция Монте-Карло (Стресс-тест портфеля)
- **Стохастическое моделирование:** прогон 5 000 рыночных траекторий с учётом реальной волатильности и кризисных просадок.
- **Два алгоритма генерации:**
  - *Geometric Brownian Motion (GBM):* параметрическое моделирование случайных блужданий цен.
  - *Исторический бутстреп:* моделирование на базе реальных исторических шоков и кризисов (2008, 2014, 2020, 2022).
- **Режимы анализа:** «Жизнь с капитала» (оценка риска банкротства), «Накопление» (DCA) и «Полный цикл».
- **Метрики риска:** вероятность успеха, безопасная ставка изъятия (SWR), квантили распределения (p5, p25, p50, p75, p95), веерный график с линейной и логарифмической шкалой.

### 3. Сравнение доходности классов активов (2003–2026)
- **Исторический бэктест 16 инструментов:**
  - Акции РФ (индекс полной доходности MCFTR)
  - Облигации ОФЗ (RGBITR) и корпоративные бонды
  - Банковские депозиты (РФ и РБ)
  - Недвижимость (Москва IRN, Минск Realt.by)
  - Драгоценные металлы: Золото (XAU), Серебро (XAG)
  - Криптовалюта: Bitcoin (BTC)
  - Глобальные ETF: S&P 500 (VOO / IVV), Всемирные акции (VWCE / IWDA), Дивидендные акции США (SCHD), Высокие дивиденды (VYM), Облигации США/Мира (AGG), Фонды недвижимости REIT (VNQ)
- **Сбалансированный портфель 1/N:** автоматический расчёт равновзвешенного диверсифицированного портфеля.
- **Стратегии инвестирования:** разовое вложение (Lump Sum) или регулярные ежемесячные довнесения (DCA).
- **Метрики эффективности:** итоговый капитал, множитель роста (xN), среднегодовая доходность (CAGR), реальная доходность сверх инфляции, максимальная историческая просадка.

### 4. Каталог и дорожная карта инструментов (Roadmap)
Помимо основных модулей FIRE, Монте-Карло и бэктеста активов, платформа включает каталог из 15 прикладных финансовых калькуляторов:
- ⏳ **В активной разработке (скоро):**
  - *Калькулятор сложного процента:* капитализация, регулярные довнесения и визуализация силы времени.
  - *Кредитный и ипотечный калькуляторы:* аннуитетные и дифференцированные графики, досрочные погашения.
  - *Калькулятор инфляции и покупательной способности:* оценка обесценения денег на долгой дистанции.
  - *Калькулятор пассивного дохода:* расчёт капитала для желаемой ежемесячной ренты.
  - *Калькулятор дивидендов и реинвестирования:* DRIP-моделирование и лавинообразный рост дивидендного потока.
  - *Калькулятор налогового вычета ИИС:* возврат НДФЛ по типам А и Б / ИИС-3.
  - *Калькулятор финансовой подушки:* расчёт размера резервного фонда по профессиям и рискам.
  - *Калькулятор автокредита, валютного хеджа и пенсионного стажа.*

### 5. Архитектура и UX
- **Мультивалютность:** полная поддержка RUB (₽), BYN (Б), USD ($), EUR (€) с конвертацией доходностей и курсов.
- **Единый 4-этапный интерфейс:** последовательная структура (1. Параметры ввода в карточках ➔ 2. Лидерборд и KPI ➔ 3. Таблица результатов ➔ 4. График динамики капитала).
- **Контекстные справки (`?`):** встроенные модальные окна с простыми объяснениями параметров, формулами, историческими примерами и советами инвестору.
- **Автосохранение данных:** мгновенная синхронизация всех полей и переключателей в LocalStorage.

## 🛠 Технологический стек

- **Фреймворк:** Next.js 15 (App Router, Server Components + Client Hydration)
- **Язык:** TypeScript 5.7+ (строгая типизация)
- **Стилизация:** Tailwind CSS
- **Графика и чарты:** Recharts
- **Иконки:** Lucide React
- **Тестирование:** tsx + кастомный модульный тест-раннер математического ядра (100% pass)

## 🚀 Быстрый старт

### Требования
- Node.js 18.18+ или 20+
- npm, pnpm или yarn

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ykr0p/finance-toolbox.git
   cd finance-toolbox
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу [http://localhost:3000](http://localhost:3000).

4. **Запуск тестов:**
   ```bash
   npm test
   ```

5. **Сборка для продакшна:**
   ```bash
   npm run build
   npm run start
   ```
