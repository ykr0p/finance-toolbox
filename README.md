# Калькулятор раннего выхода на пенсию (FIRE) — Модель Бабайкина 2.0

Интерактивный модуль симуляции раннего выхода на пенсию, созданный в строгом соответствии с Excel-моделью канала «На пенсию в 35 лет» (Бабайкин, Версия 2.0).

## Стек технологий
- **Фреймворк:** React (Next.js 15 App Router) + TypeScript
- **Стилизация:** Tailwind CSS
- **Графики:** Recharts (адаптивный график роста капитала и инфляционной цели с точкой пересечения)
- **Иконки:** Lucide React
- **Ядро расчетов:** Чистые математические функции на TypeScript (`src/lib/calculator.ts`), без внешних зависимостей.

---

## Режимы расчета (Вкладки)

### 1. «Простая версия» (Быстрый расчет)
Базовый расчет с минимальным набором понятных параметров:
- **Возраст (`age`)**: Стартовый возраст.
- **Ежемесячный доход (`monthly_income`)** и **Расходы (`monthly_expenses`)**.
- **Личная инфляция (`personal_inflation`, %)**: Ежегодный рост расходов.
- **Индексация сбережений (`savings_indexation`, %)**: Ежегодный рост довнесений.
- **Активы (`current_assets`)** и **Стоимость пассивов (`liabilities_value`)**.
- **Дивидендная доходность (`dividend_yield`, %)** и **Рост тела капитала (`capital_growth`, %)**.
- **Множитель капитала (`capital_multiplier`)**: `1` (100% покрытие расходов дивидендами) или `2` (дивиденды в 2 раза превышают расходы).

### 2. «Гибкая версия» (Детальный расчет)
Расширенная версия с учетом защитных механизмов:
- **Подушка безопасности в месяцах (`cushion_months`)**: Автоматически рассчитывается и ребалансируется с учетом растущих расходов.
- **Стоимость краткосрочных долгов (`short_term_debts`)**: Вычитается из стартового капитала.
- **Доходность подушки безопасности (`cushion_yield`, %)**: Процент по вкладам или фондам ликвидности (LQDT).
- **Процент дивидендов на потребление (`dividend_consumption_pct`, %)**: Доля дивидендов, идущая на жизнь на пенсии; оставшаяся часть реинвестируется для защиты от инфляции.

## Математическая логика (`src/lib/calculator.ts`)

### Шаг 1. Предварительные расчеты (Старт/Сегодня)
- `monthly_savings = monthly_income - monthly_expenses`
- `starting_cushion = monthly_expenses * cushion_months` (в гибкой версии)
- `initial_assets` и `initial_cushion`: распределение стартовой чистой стоимости (активы + пассивы - долги)
- `target_capital_today`:
  - В простой: `(monthly_expenses * 12 * capital_multiplier) / dividend_yield`
  - В гибкой: `(monthly_expenses * 12 / (dividend_consumption_pct / 100)) / dividend_yield + starting_cushion`

### Шаг 2. Годовой цикл симуляции (от 1 до 50 лет)
Для каждого года $i$:
1. $age_i = age_{start} + i$
2. $expenses_i = expenses_{prev} \times (1 + personal\_inflation)$
3. $cushion\_required_i = (expenses_i / 12) \times cushion\_months$
4. $target\_capital_i$: целевой капитал с учетом инфляции и доли потребления
5. $cushion\_income = cushion_{start} \times cushion\_yield$
6. $capital\_body\_growth = assets_{start} \times capital\_growth$
7. $dividends = assets_{start} \times dividend\_yield$
8. **Довнесения ($savings\_added$):** На этапе накопления рассчитываются с учетом ежегодной индексации. **После выхода на пенсию довнесения равны 0.**
9. **Дивиденды:**
   - Накопление ($Capital < Target$): 100% дивидендов реинвестируются.
   - Пенсия ($Capital \ge Target$): Доля потребления выплачивается на жизнь, остаток реинвестируется.
10. **Ребалансировка подушки и активов:** Подушка пополняется до требуемого размера ($cushion\_required_i$), остаток направляется в активы.

### Шаг 3. Условие выхода на пенсию
Пенсия считается достигнутой, когда накопленный капитал достигает или превышает целевую сумму ($TotalCapital \ge TargetCapital$), либо когда дивиденды на потребление покрывают годовые расходы.
